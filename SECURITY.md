# Security Policy

AlgoViz is in pre-release design. For reports about work in this repository, identify the affected commit or branch.

## Report a vulnerability

Submit a [private vulnerability report](https://github.com/FlowSilver/AlgoViz/security/advisories/new). Describe what is affected, the potential impact, and the minimum information needed to verify the problem. Use synthetic examples or remove secrets and personal data from shared traces and logs.

Use the private report thread for follow-up and disclosure coordination. Use [GitHub Issues](https://github.com/FlowSilver/AlgoViz/issues) for ordinary bugs.
