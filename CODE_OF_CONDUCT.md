# Code of Conduct

AlgoViz welcomes contributors of all backgrounds and experience levels. Give feedback on the work, explain disagreements respectfully, and make room for people to ask questions. Harassment, discriminatory remarks, threats, personal attacks, and sharing someone else's private information without permission are unacceptable.

These standards apply to project spaces, including issues, pull requests, and code reviews. Maintainers may remove harmful content or restrict participation based on the behavior and its impact.

Use GitHub's **Report content** option for abusive behavior in project threads. Choose **Report to repository admins** when available or report directly to GitHub Support through its abuse form. Include a link and relevant context. [GitHub reporting guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
